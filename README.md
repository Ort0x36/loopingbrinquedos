# Looping Brinquedos

Landing page de preview para a Looping Brinquedos (locação de brinquedos para festas, Praia Grande/SP).

Site estático em um único arquivo (`index.html`). Para configurar o WhatsApp comercial, edite a variável `WHATSAPP_NUMBER` no final do arquivo (DDI + DDD + número, só dígitos, ex.: `5513900000000`).

Deploy: Vercel, framework "Other", sem build.
